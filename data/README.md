# Data Directory

## Dataset Source
- **Name:** IBM Telco Customer Churn Dataset
- **URL:** https://www.kaggle.com/datasets/blastchar/telco-customer-churn
- **File:** `raw/WA_Fn-UseC_-Telco-Customer-Churn.csv`
- **License:** Public domain (IBM sample dataset)

## How to Download
1. Visit the Kaggle link above
2. Sign in to Kaggle (free account required)
3. Click Download
4. Place the CSV file in `data/raw/`

## Data Dictionary

| Column | Type | Description |
|--------|------|-------------|
| customerID | string | Unique customer identifier (dropped in preprocessing) |
| gender | binary | Customer gender: Male=1, Female=0 |
| SeniorCitizen | binary | Age 65+: Yes=1, No=0 |
| Partner | binary | Has a partner: Yes=1, No=0 |
| Dependents | binary | Has dependents: Yes=1, No=0 |
| tenure | numeric | Months as a customer (0–72) |
| PhoneService | binary | Has phone service: Yes=1, No=0 |
| MultipleLines | categorical | No / Yes / No phone service |
| InternetService | categorical | DSL / Fiber optic / No |
| OnlineSecurity | categorical | No / Yes / No internet service |
| OnlineBackup | categorical | No / Yes / No internet service |
| DeviceProtection | categorical | No / Yes / No internet service |
| TechSupport | categorical | No / Yes / No internet service |
| StreamingTV | categorical | No / Yes / No internet service |
| StreamingMovies | categorical | No / Yes / No internet service |
| Contract | categorical | Month-to-month / One year / Two year |
| PaperlessBilling | binary | Uses paperless billing: Yes=1, No=0 |
| PaymentMethod | categorical | Electronic check / Mailed check / Bank transfer / Credit card |
| MonthlyCharges | numeric | Monthly charge in USD (18.25–118.75) |
| TotalCharges | numeric | Total charges in USD — fixed from object to float |
| Churn | binary | **TARGET** Did customer churn? Yes=1, No=0 |
